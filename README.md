# Casa Semente

Site demonstrativo de uma ONG comunitária, feito com HTML semântico, CSS e JavaScript nativo.

## Site da ONG

- `index.html`: apresentação institucional e formas de contato.
- `projetos.html`: iniciativas comunitárias, doações e voluntariado.
- `cadastro.html`: formulário com validações HTML5 e máscaras de CPF, telefone e CEP.
- `src/site.css` e `src/site.js`: estilos e interações do site.
- `assets/`: fotografias otimizadas em WebP e JPEG.

Abra `index.html` em um navegador moderno. Não é necessário instalar ferramentas nem iniciar servidor. Os dados de contato são demonstrativos; o formulário valida no navegador e não envia nem armazena dados.
