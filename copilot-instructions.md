# Instrucoes do projeto Casa Semente

- Este projeto e um site demonstrativo de ONG, feito com HTML semantico, CSS e JavaScript nativo.
- Preserve a compatibilidade com abertura direta de `index.html`; nao adicione dependencias ou etapa de build sem necessidade.
- Mantenha as paginas `index.html`, `projetos.html` e `cadastro.html`, com estilos e scripts do site em `src/` e imagens em `assets/`.
- Preserve navegacao acessivel, rotulos de formulario, textos alternativos de imagem e suporte a telas pequenas.
- O formulario e demonstrativo: nao envie nem armazene os dados pessoais informados.
- Use nomes e ilustracoes originais; substitua os contatos demonstrativos apenas quando os dados reais forem fornecidos.
